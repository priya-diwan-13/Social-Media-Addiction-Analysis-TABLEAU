# Social-Media-Addiction-Analysis-TABLEAU

A Tableau Data Visualization project focused on analyzing social media usage patterns, user behavior, addiction levels, and engagement trends. The project uses Python for data preprocessing and Tableau for interactive data visualization and dashboard development.

## Project Objective

The main objective of this project is to analyze social media usage and addiction patterns to understand user behavior, usage frequency, engagement levels, and other factors related to social media addiction.

The cleaned dataset is visualized through an **interactive Tableau dashboard** to identify important patterns and generate meaningful insights.

## Technologies Used

- **Python** – Data cleaning and preprocessing
- **Tableau** – Interactive dashboard, data visualization, and insights

## Project Workflow

### 1. Data Preprocessing – Python

The raw social media dataset was cleaned and prepared using Python and Pandas.

The main preprocessing steps included:

- Loaded and explored the raw dataset
- Checked and handled missing values
- Replaced invalid `ERROR_VALUE` entries
- Filled missing values in categorical and numerical columns
- Checked for duplicate records
- Prepared and exported the cleaned dataset

### 2. Visualization & Dashboard – Tableau

The cleaned dataset was imported into Tableau to create an **interactive dashboard**.

The dashboard focuses on:

- Social media usage and user behavior
- Addiction-related patterns
- Usage, sleep, and productivity analysis
- Mood and study patterns
- Notification, screen unlock, and weekend usage

Interactive **filters, KPIs, and charts** allow users to explore the data and identify key patterns and insights.
